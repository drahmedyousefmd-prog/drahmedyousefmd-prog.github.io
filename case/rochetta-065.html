الجهاز الهضمي

GERD & Peptic Ulcer

Heartburn, epigastric pain, acid reflux

تحذير
Alarm signs: dysphagia, weight loss, vomiting blood, black stools — refer for endoscopy.
  • - Burning epigastric pain / retrosternal burning
  • - Worse after meals or lying down, relieved partly by antacids
  • - Alarm features (weight loss, bleeding, dysphagia) need endoscopy
  • - Lab: FBC (anaemia from bleeding), LFTs; H. pylori testing if ulcer suspected
  • - Special test: Endoscopy (OGD) — indicated with alarm features or refractory symptoms
  • - Monitor: Response to PPI trial, symptom control, red flag symptoms at each visit
  • - Biopsy: Endoscopic biopsy for H. pylori if ulcer/atrophic changes
  • - PPIs are prodrugs, activated only in acidic environment
  • - Must be taken 30–60 min before a meal to work properly
  • - H2 blockers are a good alternative if PPIs not tolerated
